# All Canil Oficinas

Site institucional da **All Canil Oficinas** — Pet Shop, Banho e Tosa, Clínica Veterinária e Farmácia Pet em Ponta Grossa (PR).

## Repositório

https://github.com/leoanrdotst2026-cloud/all-canil-oficinas

## Como publicar o site completo

1. Baixe o arquivo `allcanil-site.zip` (enviado no chat)
2. Extraia a pasta (`index.html` + pasta `img/`)
3. No GitHub: **Add file → Upload files**
4. Arraste `index.html` e a pasta `img/`
5. Commit

### GitHub Pages (site online grátis)

1. **Settings → Pages**
2. Source: **Deploy from a branch**
3. Branch: `main` / folder: `/ (root)`
4. Save

Em 1–2 minutos o site fica em:
**https://leoanrdotst2026-cloud.github.io/all-canil-oficinas/**
